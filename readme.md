## 🚀 Overview

**Nexora AI** is a web-based AI assistant designed to combine conversational AI with external tools.

Instead of relying only on the language model's internal knowledge, Nexora can use specialized tools when required.

### Core capabilities

- 🤖 AI-powered conversations
- 🔎 Real-time web search
- 🌤️ Current weather information
- 🧠 LangChain tool-calling agent
- 💬 Persistent conversation history during a session
- ⚡ Flask backend
- 🎨 Modern responsive AI interface
- 📱 Mobile, tablet and desktop support
- ☁️ Cloud deployment ready
- ❤️ Health monitoring endpoint

---

# ✨ Features

## 🤖 Intelligent AI Assistant

Nexora uses an LLM through OpenRouter and LangChain's tool-calling agent architecture.

The assistant can determine when a tool is useful and invoke it automatically.
